Flag Admin Web

Aplicação web de gestão da Flag Platform — cadastro de organizações, campeonatos, times, elencos, atletas, rodadas, jogos e campos. Flutter Web com Riverpod (estado) e GoRouter (navegação).

Estrutura de pastas

lib/src/
├── api/          # Cliente HTTP (ApiClient) + services por recurso
├── core/         # Tema, tokens, widgets compartilhados (Kickster)
├── domain/       # Modelos e enums de domínio
├── providers/    # Providers Riverpod (API, listas, seleções)
├── router/       # GoRouter (app_router.dart) + AdminShell
├── screens/      # Telas (uma classe por tela)
├── widgets/      # Widgets reutilizáveis (modais, cards, formulários)
└── utils/        # Helpers (datas, máscaras, mutações)

Navegação em resumo

O app usa um StatefulShellRoute.indexedStack com uma branch por módulo (preserva estado por branch). A navegação entre módulos é feita pelos cards da home com context.go. Telas de detalhe/formulário usam push / pop para manter o histórico. Todas as telas (exceto a home) exibem um botão voltar no topo.
