# Domain docs: single-context

Layout: single-context (one `CONTEXT.md` at repo root, plus `docs/adr/` for ADRs).

Consumer rules:
- Always read `CONTEXT.md` first for current context and decisions.
- ADRs in `docs/adr/` provide historical rationale for architectural decisions.
- When adding new decisions, create a new ADR file in `docs/adr/`.
